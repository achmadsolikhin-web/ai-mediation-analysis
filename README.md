# AI Dependency, Burnout, and Career Readiness

## Overview
This project analyzes whether burnout mediates the relationship between AI dependency and career readiness among students using Baron & Kenny mediation analysis in R.

## Dataset
Source:  
https://www.kaggle.com/datasets/sridipbasu/ai-depndency-career-anxiety-and-student-burnout

## Methods
- Exploratory Data Analysis (EDA)
- Linear Regression
- Baron & Kenny Mediation Analysis
- Subgroup Analysis

## Tools
- R
- tidyverse
- ggplot2
- R Markdown
- Git & GitHub

## Key Findings
- Higher AI dependency is associated with higher burnout.
- Burnout negatively affects career readiness.
- Burnout partially mediates the relationship.
